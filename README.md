# Ruby Refactoring and Design Patterns

Code from the [I'll Be Backend](https://www.youtube.com/@illbebackend) videos: messy Ruby code gets better, one small, safe refactoring at a time. Every lesson has a video, an [interactive version](https://illbebackend.dev) you can step through, and a folder here with the code after every step.

|---|---|---|---|
| [DRY: one rule, one place](dry/) | 11 | [Watch](https://www.youtube.com/watch?v=r1Td7g3A-qU) | [Open](https://illbebackend.dev/lessons/dry/ruby/) |
| [Clean code: rename for intent](rename-for-intent/) | 13 | [Watch](https://www.youtube.com/watch?v=NeA0d_iM75Y) | [Open](https://illbebackend.dev/lessons/rename-for-intent/ruby/) |

## How to use it

- Open a lesson folder and read its README, then the step folders in order.
- `sh check.sh` compiles every step in Docker with `ruby:3.3-slim`, the same check every lesson passed before its video went out.
- Found a bug in a lesson? Open an issue.
